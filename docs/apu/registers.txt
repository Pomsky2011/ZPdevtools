# ZeroPoint APU Register Reference

## Register Overview

The APU has exactly two general-purpose 8-bit registers, X and Y, plus several
special-purpose registers. (The emulator happens to allocate a 256-entry array
for them; see "The 7-bit destination field" below. Only the first two entries
are registers.)

### General Purpose Registers
- **R0 (X)** (8-bit) - Primary accumulator/index register
- **R1 (Y)** (8-bit) - Secondary accumulator/index register

Note: Every instruction that reads or writes a register (NOR, AND, ADD, SUB, ADC,
SBC, XOR, CRB, STA, MOV, comparisons, ...) encodes it in 1 bit (0=R0/X, 1=R1/Y),
with one exception: the result field of NOR/AND/ADD/SUB/ADC/SBC is 7 bits wide
(see below).

### Special Purpose Registers
- **PC** (Program Counter) - 16-bit, tracks current instruction address
- **SP** (Stack Pointer) - 16-bit, hardware stack pointer
- **RP** (ROM Page) - 8-bit, high byte for jump target addressing
- **DP** (Data Page) - 8-bit, high byte for memory addressing
- **DB** (Data Byte) - 8-bit, secondary memory addressing byte
- **BF** (Byte Flip) - 1-bit, reserved: no instruction sets it, so it is always 0
- **FLAGS** - 4-bit status flags register (0bzglc)

---

## Detailed Register Descriptions

### R0 / X Register (8-bit)

**Purpose:** Primary general-purpose register. Encoded as source operand 0 in arithmetic.

**Can Be Used In:**
- NOR, AND, ADD, SUB, ADC, SBC, XOR (source/destination)
- STA, STR / LDA (data storage/loading)
- SCR (load immediate constant)
- ZOR, ZOA (zero out)
- BEQ, BNE, BLT, BGT (conditional branches)
- CME, CMN, CML, CMG (compare-and-jump)
- JNZ, JZ (conditional jumps)
- MOV, EXC (register transfer/exchange)
- INC, DEC (increment/decrement)
- PUX, POX (push/pop to hardware stack)

**Common Use Cases:**
```
LDA X, 42         ; X = 42
ADD X, Y, X       ; X = X + Y
STA X, $50        ; Store X to [DP:$50]
JNZ X, $10        ; Jump to [RP:$10] if X != 0
```

---

### R1 / Y Register (8-bit)

**Purpose:** Secondary general-purpose register. Encoded as source operand 1 in arithmetic.

**Can Be Used In:**
- All same instructions as R0/X
- Typically used as the second operand in binary operations

**Common Use Cases:**
```
LDA X, 10
LDA Y, 20
ADD X, Y, X       ; X = 30
BEQ X, Y, $50     ; Branch to [RP:$50] if X == Y
```

---

### The 7-bit destination field (not extra registers)

**Purpose:** None. There are only two registers. The result field of
NOR/AND/ADD/SUB/ADC/SBC is 7 bits wide as an artifact of the encoding, and
`apuasm` will accept names up to R127 there, but values 2-127 only store the
result in an internal array slot that no instruction can read back. They are
not registers and cannot hold anything usable. Write results to X, Y, or a
memory byte ($DP:$YY), and use `PUX`/`PUY` or a RAM scratch page to spill values.

---

### PC - Program Counter (16-bit)

**Purpose:** Address of the currently executing instruction.

**Characteristics:**
- 16-bit (full 64 KiB address space)
- Increments by 2 after each instruction fetch
- Modified by all jump/branch/call/return instructions

**Modification Instructions:**
- `JMP` — relative or absolute jump, always pushes a return address
- `JMS $ZZ` / `JDP` — plain goto (to $RPZZ / to $DPDB), no push
- `JSR $ZZ` / `JDPS` — call (pushes return address)
- `JMX` / `JSX` — goto / call to the address in Y:X
- `RET` — return (pops return address)
- `JNZ X, $ZZ` — if R0/R1 != 0: push return address and jump to $80ZZ (BIOS page only)
- `JZ X, $ZZ` — if R0/R1 == 0: jump (no push)
- `BEQ/BNE/BLT/BGT X, Y, $ZZ` — compare-and-branch to $RPZZ
- `CME/CMN/CMG/CML` — compare and jump a short relative distance

**Executable Regions:**
The core fetches instructions from any address, so code can run from RAM
($0100-$0FFF), ARAM ($3000-$6FFF, where a CPU-uploaded program lives), the
BIOS ($8000-$8FFF) or AROM ($D000-$FFFF, banked). Instructions are 2 bytes wide
and PC advances by 2 after each fetch.

---

### SP - Stack Pointer (16-bit)

**Purpose:** Hardware stack pointer. Manages the call stack and push/pop operations.

**Characteristics:**
- 16-bit register
- Grows UP: a push writes the byte at SP and then increments SP; a pop decrements SP and then reads
- A call pushes the return address high byte first, then the low byte
- Managed automatically by push/pop and call/return instructions
- Can be manually adjusted with `INC SP` / `DEC SP`
- Reset value is $0000, so it must be initialized with `BSP` before the first call

**Instructions that use SP:**
- `PUX` — push R0 (X) onto stack
- `PUY` — push R1 (Y) onto stack
- `PUDP` — push DP and DB onto stack
- `POX` — pop from stack into R0 (X)
- `POY` — pop from stack into R1 (Y)
- `PODP` — pop DP and DB from stack
- `JSR $ZZ` / `JDPS` / `JSX` — pushes return address (2 bytes)
- `JMP` / taken `JNZ` — also push a return address
- `RET` — pops return address (2 bytes)
- `INC SP` / `DEC SP` — manual SP adjustment
- `BSP` — SP = X (low byte) | Y (high byte) << 8

**Set By:**
```
lda x, $00
lda y, $01
bsp           ; SP = $0100 (initial stack setup, in General RAM)
inc sp        ; SP++
dec sp        ; SP--
```

**Stack Layout Example:**
```
; Stack grows up from $0100
scr x, $00
scr y, $01
bsp           ; SP = $0100
jsr func      ; pushes the return address: SP = $0102
```

---

### RP - ROM Page Register (8-bit)

**Purpose:** High byte of jump target addresses.

**Used In:**
- `JMS $ZZ` → jumps to $RPZZ
- `JSR $ZZ` → calls $RPZZ (pushes return address)
- `JMP` with D=1, M=1 → pushes, then jumps to $RPZZ
- `JZ X, $ZZ` → jumps to $RPZZ if X == 0
- `BEQ/BNE/BLT/BGT X, Y, $ZZ` → conditional branch to $RPZZ

**Set By:**
```
SRP $D0       ; RP = $D0
```

**Example:**
```
SRP $80       ; Set RP to BIOS region
JMS $10       ; Jump to $8010

SRP $D0       ; Set RP to AROM region
BEQ X, Y, $50 ; If X == Y, jump to $D050
```

**Memory Page Mapping:**
```
RP=$00 → Jumps to $00XX (MMP registers)
RP=$01 → Jumps to $01XX (RAM)
RP=$10 → Jumps to $10XX (DEF88186 Input)
RP=$80 → Jumps to $80XX (BIOS)
RP=$D0 → Jumps to $D0XX (AROM)
```

---

### DP - Data Page Register (8-bit)

**Purpose:** High byte for memory data addresses.

**Used In:**
- `STA X, $YY` → stores to $DPYY
- `STR $YY, X` → loads from $DPYY
- `NOR/AND/ADD/SUB/ADC/SBC/XOR` with memory destination → result to $DPZZ
- `ZOA $XX` → zeros the word at $DPXX
- `LDA X` / `STA X` / `STA $XX` → load/store the byte at $DPDB
- `STRX` / `STAX` → load/store the byte at $DP:(X or Y)
- `JDP` / `JDPS` → jumps to $DPDB (combined with DB)

**Set By:**
```
SDP $30             ; DP = $30 (immediate)
SDP 1, $XX          ; same as SDP $XX (SDP 0, $XX sets DB instead)
PODP                ; Pop DP from stack
```

**Common Values:**
```
SDP $00  ; MMP control registers
SDP $01  ; General RAM
SDP $10  ; DEF88186 Input
SDP $18  ; DEF88186 Output
SDP $30  ; ARAM
SDP $70  ; STL
SDP $80  ; BIOS (read-only)
SDP $90  ; SST
SDP $D0  ; AROM (read-only)
```

**Example:**
```
SDP $10       ; DP = $10
LDA X, 42
STA X, $50    ; Store 42 to $1050

SDP $90       ; DP = $90 (SST region)
STR $00, X    ; Load from $9000 into X
```

**Notes:**
- Push/pop with `PUDP`/`PODP` for context switches
- Set once and access multiple offsets in same page

---

### DB - Data Byte Register (8-bit)

**Purpose:** Low byte of the (DP:DB) address used by the one-argument load/store forms and the indirect jumps.

**Used In:**
- `LDA X` / `STA X` / `STA $XX` → load/store the byte at ($DP << 8) | $DB
- `JDP` → jumps to address formed as ($DP << 8) | $DB
- `JDPS` → calls address ($DP << 8) | $DB (pushes return address)

**Set By:**
```
SDB $50       ; DB = $50
SDP 0, $50    ; same thing
```

**Example:**
```
SDP $D0       ; DP = $D0
SDB $40       ; DB = $40
JDP           ; Jump to $D040
```

**Notes:**
- Not used by the two-argument STA/STR forms (those use $DPYY directly) or by STRX/STAX
- `PUDP`/`PODP` save and restore DP and DB together

---

### BF - Byte Flip Register (1-bit, reserved)

The core carries a BF bit that the memory-destination ALU forms and STA/STR
consult to pick the low or high byte of a word, but **no instruction sets it**
(the original `SBF` instruction's opcode was reused for `LDA`/`STA`), so BF is
always 0 and every access is to the byte at the address you name.

To touch a 16-bit value, address its two bytes directly (low byte at the lower
address):
```
SDP $10
STR $50, X    ; X = low byte of the word at $1050
STR $51, Y    ; Y = high byte
```
```
SDP $20
LDA X, $CD
LDA Y, $AB
STA X, $30    ; low byte  -> $2030
STA Y, $31    ; high byte -> $2031; the word at $2030 now holds $ABCD
```

---

### FLAGS - Status Flags Register (4-bit)

**Purpose:** Condition codes set by arithmetic/compare instructions.

**Bit Layout:** `0b0zglc` (4 bits)
```
Bit 3 (0x08): Z = Zero flag      — result was zero
Bit 2 (0x04): G = Greater flag   — left operand > right
Bit 1 (0x02): L = Less flag      — left operand < right
Bit 0 (0x01): C = Carry flag     — arithmetic carry/borrow
```

**Set By:**
| Instruction | Flags Affected         |
|-------------|------------------------|
| ADD X, Y    | Z, C                   |
| SUB X, Y    | Z, C, G, L             |
| ADC X, Y    | Z, C                   |
| SBC X, Y    | Z, C, G, L             |
| CME/CMN/CML/CMG | Z, G, L           |
| BEQ/BNE/BLT/BGT | Z, G, L (before branch) |
| SF mask     | FLAGS |= mask          |
| CF mask     | FLAGS &= ~mask         |
| SFR mask    | FLAGS = mask           |
| STF X/Y     | upper nybble of X/Y = FLAGS |

**Read By:**
- `BEQ/BNE/BLT/BGT` — branch based on Z/G/L
- `ADC/SBC` — reads C flag to include carry
- `STF X` — reads FLAGS into X for manual inspection

**Flag Instructions** (the operand is a 4-bit mask of Z=0x8, G=0x4, L=0x2, C=0x1):
```
SF 0x1        ; Set carry flag (FLAGS |= 0x01)
SF 0x2        ; Set less flag
SF 0x4        ; Set greater flag
SF 0x8        ; Set zero flag
CF 0x1        ; Clear carry flag
CF 0x2        ; Clear less flag
SFR 0x0       ; Set FLAGS to the given mask (here: clear all)
STF X         ; X = (X & 0x0F) | (FLAGS << 4)
```

**Example - Carry Arithmetic:**
```
; Add 16-bit values ($0201:$0200) + ($0203:$0202) -> ($0205:$0204)
SDP $02
STR $00, X
STR $02, Y
ADD X, Y, $04     ; low + low (sets C on overflow), stored to $0204
STR $01, X
STR $03, Y
ADC X, Y, $05     ; high + high + carry, stored to $0205
```

**Example - Manual Flag Check:**
```
; Branch if the last ADD carried
ADD X, Y, X
STF Y             ; Y's upper nybble = FLAGS: Z=bit 7, G=bit 6, L=bit 5, C=bit 4
SCR X, $10        ; mask for the carry bit
AND X, Y, X       ; X = Y & $10, nonzero if carry was set
JZ X, no_carry    ; JZ jumps when X == 0
```

## Register Usage Conventions

### Function Calling Convention

**Arguments (caller-provided):**
- R0 (X), R1 (Y) for up to 2 single-byte parameters
- Additional args pushed on stack before call

**Return values:**
- R0 (X) for single byte
- R0 (X) + R1 (Y) for two bytes

**Caller-saved (caller must preserve if needed):**
- R0 (X), R1 (Y), FLAGS

**Callee-saved (callee must preserve):**
- RP, DP, DB (use PUDP/PODP for DP and DB)

**Call/Return Example:**
```
; Caller
LDA X, 5      ; arg0 = 5
LDA Y, 3      ; arg1 = 3
SRP $D0
JSR $40       ; call multiply at $D040
; X = result

; Callee (multiply: X * Y)
multiply:
  PUY           ; save Y across loop
  ; ... compute ...
  POY           ; restore Y
  RET
```

### Stack Operations

The APU has hardware stack instructions. No manual SP tracking needed:

```
PUX           ; push X
PUY           ; push Y
PUDP          ; push DP
JSR $XX       ; call (auto-pushes return address)
RET           ; return (auto-pops return address)
POX           ; pop into X
POY           ; pop into Y
PODP          ; pop into DP
```

**Saving/restoring a register across a call:**
```
PUX           ; save X
JSR $XX       ; call function (may clobber X)
POX           ; restore X
```

## Register State on Reset

On APU reset:
- PC: $8000 (BIOS entry point)
- SP: $0000 (not usable until BSP sets it)
- RP: $80 (so JSR/JMS/branches reach the BIOS page)
- DP, DB, BF: $00, $00, 0
- FLAGS: $00 (all clear)
- R0-R255: zeroed

**Recommended Boot Sequence:**
```
start:
  SRP $80       ; RP -> the page this code lives in
  SDP $01       ; DP -> RAM
  SDB $00       ; DB = 0
  SFR 0x0       ; clear all flags
  SCR X, $00
  SCR Y, $01
  BSP           ; SP = $0100
  ; ... initialize RAM, then jump to main
```
