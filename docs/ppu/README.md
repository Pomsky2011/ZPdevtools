# PPU: the graphics processor

The PPU is a small graphics processor with its own instruction set and 64 KiB of memory. It runs a program in step with the
display beam and draws into a rolling framebuffer, using tiles, palettes and a set of background blitters. The CPU loads its
program and starts it.

## In one screen

- **64 sixteen-bit registers.** `R59` and `R60` hold the V-blank and H-blank handler addresses, `R61` is the stack pointer (grows
  up), `R62` is the **jump target register**, `R63` is the data pointer.
- **Every instruction is 16 bits, big-endian, and costs 1 to 16 cycles.** One display line is 340 cycles.
- **Constants are built a byte at a time** through four target registers: a 16-bit constant is four instructions, 8 cycles.
- **Only `CMP` sets flags.** Jumps go to the address in `R62`, so a jump to a label first loads `R62`.
- **Drawing is mostly asynchronous.** `TILEDRAW` hands a tile to one of 8 blit channels and returns; blits land in issue order.
- **The framebuffer is a rolling window**, so rows must be drawn while they are in it. The tile-row queue exists to do that
  timing for you.

## Three things that will bite you

1. **An interrupt can wedge a `JMR label` loop.** `RET` leaves `R62` holding the interrupted address, and a loop that is between
   loading `R62` and jumping then jumps to itself forever (28 of 77 arrival cycles, measured). Wait for interrupts with a bare
   `JMR` spinning on itself. See [architecture.md](architecture.md).
2. **The jump shorthands overwrite target registers 0 and 1.** Use 2 and 3 for your own constants.
3. **`SETBYTE` takes one byte.** A plain number over 255 is an error, not truncated; only a label is split into its low and high byte.

## How these pages were checked

- [encodings.md](encodings.md) is generated by `scripts/gen_ppu_docs.py`: every form is assembled with `ppuasm`, split into its
  fields and disassembled with `ppudisasm`; shorthand expansions are the disassembly of the assembler's own output.
- The programs in [programming-guide.md](programming-guide.md) were run on the emulator (registers, a pixel, and a V-blank counter
  at three cycle counts), and the interrupt hazard was measured by raising the interrupt at every cycle of the loop.
  `python3 scripts/check_doc_asm.py` assembles every `ppuasm` block.
- Costs and port addresses are from the emulator's `src/ppu.cpp` and `include/ppu.h`.
