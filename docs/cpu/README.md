# DEF88186 main CPU

The DEF88186 is the ZeroPoint's main processor: a 16-bit, 24-bit-addressed, little-endian CPU descended from the
65C816, with a hardware multiplier and divider, a hardware loop counter and a block mover. It runs at 17.002839 MHz
(master clock / 4) and controls everything else: the PPU, APU and DMA are all driven through its address space.

These pages describe what the emulator (revision 10, which is frozen) actually does. Where an older document, a
comment or the 65C816 data sheet says otherwise, the emulator wins.

## Three things that will bite you

1. **Direct page is in bank `$00`, which is cartridge ROM.** `LDA dp` reads your ROM and `STA dp` writes nothing.
   Variables belong in work RAM, reached with absolute addressing and `DB = $80`.
2. **`JMP addr` jumps into the bank in `DB`, not `PB`.** Keep `DB` equal to `PB`, or use `BRA`, `JMP long` or `JSR`.
3. **There is no `BNE`, `BPL`, `BCC` or `BVC` opcode.** The assembler fakes them with a branch over a `BRA`, so they
   cost 6 to 7 bytes.

## How these pages were checked

- [opcode-table.md](opcode-table.md) is generated by `scripts/gen_cpu_docs.py` from `spec/DEF88186.csv`,
  `spec/DEF88186-measured.tsv` and a live run of `cpuasm`. The measured file comes from the emulator's
  `tools/dump_cpu_table`, which executes every opcode from random registers, flags and memory and records its length,
  cycles, flag changes and stack movement.
- Behaviour claims in the other pages were run on the emulator while writing them, or traced to the line in
  `src/cpu.cpp` that causes them.
- `python3 scripts/check_doc_asm.py` assembles every `cpuasm` code block in these pages.
